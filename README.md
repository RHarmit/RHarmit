## Project Standard

I aim for each project to do more than calculate a metric. A strong financial tool should:

1. Make its assumptions and methodology visible
2. Validate the quality and coverage of its input data
3. Connect outputs to a financial interpretation
4. Show both return opportunities and risk limitations
5. Produce a result that another analyst can reproduce and use
